# Programmers Solutions

프로그래머스 문제를 매일 한 문제씩 풀고 기록하는 저장소입니다.

## 목표

- 매일 최소 한 문제 풀기
- 정답 코드뿐 아니라 풀이 아이디어와 복잡도 기록하기
- 다시 풀어볼 문제는 체크해 두고 주기적으로 복습하기

## 저장소 구조

```text
programmers-solutions/
├── Level-0/
├── Level-1/
├── Level-2/
├── Level-3/
├── Level-4/
├── Level-5/
└── templates/
    └── problem/
        ├── README.md
        └── solution.py
```

각 문제는 `Level-N/문제번호-문제이름/`에 저장합니다.

예시:

```text
Level-1/12903-가운데-글자-가져오기/
├── README.md
└── solution.py
```

## 풀이 현황

| 날짜 | 난이도 | 문제 | 풀이 |
|---|---:|---|---|
| - | - | 첫 문제를 기다리는 중 | - |

## 기록 원칙

- 문제 본문 전체 대신 프로그래머스 문제 링크를 남깁니다.
- 제출을 통과한 뒤 읽기 좋은 코드로 정리합니다.
- 풀이 아이디어와 시간·공간 복잡도를 짧게 기록합니다.
- 다시 풀고 싶은 문제는 문제별 README에 `복습 필요`로 표시합니다.

## 커밋 메시지

```text
solve: 12903 가운데 글자 가져오기
refactor: 12903 풀이 개선
docs: 12903 풀이 설명 추가
```
